# 导入与真机验收
- [ ] 填写自己的 AppID 和 HTTPS apiBase，编译 WXML/WXSS 无报错。
- [ ] request、downloadFile 合法域名配置完成，启用域名校验仍可请求。
- [ ] 两台手机分别登录男方和女方；错误密码失败、退出后会话失效。
- [ ] 未登录直接访问日记、互动、照片及视频，服务拒绝。
- [ ] 男方写日记，女方看到；女方不能编辑男方记录。
- [ ] 两台设备编辑同一作者同一篇日记，旧版本保存被拒绝且输入仍保留。
- [ ] 单方提交后，对方返回数据不含答案；双方提交后自动揭晓。
- [ ] 切换玩法、进入后台、恢复前台不出现重复计时器或旧玩法结果。
- [ ] 相册中无已删除图片；按需下载和放大正常。
- [ ] 视频下载和播放正常，播放另一段时前一段暂停。
- [ ] 地图只标记诸暨、绍兴，不请求实时定位。
- [ ] 断网、超时显示可重试错误，没有显示虚假的同步成功。
- [ ] 安卓与 iOS 微信分别测试，检查长文字、键盘遮挡、圆角与滚动。
- [ ] 旧日记如需迁移，备份并核对条数、作者和正文。
- [ ] 按实际服务填写微信隐私保护指引、服务类目等后台材料，完成体验版再提交审核。
